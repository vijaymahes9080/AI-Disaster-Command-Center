## 🌟 Overview

**AI Disaster Command Center** is a real-time decision-support system designed for emergency authorities, NDRF first responders, and disaster management teams. The platform ingests multi-source data (Satellite Imagery, Weather Telemetry, Social Media NLP, IoT River Sensors, Govt Alerts), executes machine learning predictive engines, and visualizes tactical GIS situation maps with automated evacuation and resource allocation matrixes.

## ⚡ Quick Start Guide

### Prerequisites
- **Node.js**: v18.0 or higher (`node -v`)
- **Python**: v3.10 or higher (`python --version`)

### 1. Clone Repository
```bash
git clone https://github.com/vijaymahes9080/AI-Disaster-Command-Center.git
cd AI-Disaster-Command-Center
```

### 2. Install Frontend Dependencies
```bash
npm install
```

### 3. Install Backend Dependencies
```bash
python -m pip install -r backend/requirements.txt
```

### 4. Run Backend Server (FastAPI)
```bash
python -m uvicorn backend.main:app --reload --port 8000
```

### 5. Run Frontend Dev Server (Vite)
```bash
npm run dev
```

Open your browser at [http://localhost:3000](http://localhost:3000) to view the AI Disaster Command Center!
